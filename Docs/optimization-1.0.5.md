# 1.0.5（20）本机优化记录

日期：2026-11-14。此记录对应本机构建与安装，不表示已发布 GitHub Release 或 Sparkle 更新。

## 本次变更

- 菜单栏主入口提前创建，迁移旧的隐藏状态与位置，提供“恢复图标”和右键打开设置。
- 设置侧栏、菜单栏弹窗及关于页显示实际运行版本；关于页显示当前应用路径，可在访达定位。
- 汽水音乐启动后先尝试恢复已有媒体会话，再在已有辅助功能授权时尝试播放器的播放按钮。等待真实播放状态，不以“已打开应用”判断播放成功。
- 已接受但尚未确认的媒体命令不会再触发第二次界面播放点击，避免反向暂停。
- 移除播放失败时的自动授权弹窗；授权入口由用户主动打开，授权返回后续接待执行的播放。
- 音乐与菜单栏收纳共用授权入口，同一进程只显示一次系统授权提示；后续直接打开系统设置。
- 汽水音乐授权失败不再阻断媒体信息刷新。已有歌曲会话恢复后清除过期的权限错误，不必重启灵动岛。
- 未授权失败后，播放按钮改为明确的“打开汽水音乐”；设置中可重新检测权限并定位当前应用。
- 仅在用户主动前往授权后等待权限变更，最多 2 分钟；绑定切换、休眠或手动打开播放器会取消自动续播。
- 播放、暂停按点击时显示的动作发送明确命令，避免媒体信息延迟时误把播放变成暂停。
- CPU、内存摘要直接打开 macOS 活动监视器。
- 播放轮询仅在灵动岛展开、设置窗口或歌曲详情可见时运行；睡眠时停止。
- 鼠标事件负责及时触发悬停，兜底轮询从每秒 30 次减至 4 次，并限制高频鼠标处理次数。
- 封面以最大 256 像素解码，缓存数量从 8 张减至 3 张，移除额外 URL 图片缓存。
- 设置按通用、音乐播放、快捷应用、外观布局、动画、触发方式、关于与更新分类；移除重复概览卡片和已隐藏功能的参数入口。
- 保留原有展开、收起动画参数；修复贝塞尔输入可忽略非法字段的问题。
- PKG 打包前总是重新构建，DMG 使用一致的构建号，避免打包旧应用。

## 尚需实机确认

- 桌面控制权限不可用，未通过自动桌面点击验证菜单栏实际可见性、悬停手感或真实歌曲播放。
- 当前汽水音乐没有通过系统媒体服务提供歌曲快照。播放状态机测试使用可控响应，并不等同于已验证汽水音乐的实际冷启动播放。
- 当前仍为 ad-hoc 签名；权限可能在重新构建后失效。长期解决需配置稳定的代码签名身份，公开分发还需正常签名与公证流程。构建安装阶段没有修改系统权限或钥匙串；后续授权诊断见下文。
- 1.0.5（19）安装后的用户反馈为“仍提示需要授权”。1.0.5（20）已修正权限恢复流程，尚待用户重新授权当前应用后实测播放，不能据模拟测试宣称实际冷启动已修复。
- 旧安装的备份位于 `Build/PreviousInstallation-1.0.4-18.app`。
