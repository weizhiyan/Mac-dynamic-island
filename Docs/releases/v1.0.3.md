# 灵动岛 1.0.3

这个版本重点修复菜单栏交互延迟，并完成自定义灵动岛编辑面板与音乐控制链路的收敛。

## Mac

- 修复点击状态栏图标后先触发菜单栏图标搬运、导致弹窗展开变慢的问题
- 菜单栏图标 AX 枚举移到后台队列，避免阻塞状态栏弹窗
- 系统隐藏的应用不再被重复执行收纳操作
- 自定义面板预览固定在顶部，参数区改为布局、收起态、展开态、动画四个 Tab
- 圆角、顶部偏移等尺寸参数调整后实时重建灵动岛布局
- 设置页合并重复配置，增加圆角参数与动画试用入口
- 未打开音乐应用时点击播放，可自动绑定并拉起已安装的播放器
- 修复音乐控制权限预检阻塞导致播放按钮失效的问题

## Windows

- Windows 版本同步更新到 1.0.3

## 说明

- Mac 安装包：`Mac-Dynamic-Island-1.0.3.pkg` / `Mac-Dynamic-Island-1.0.3-intel.pkg`
- Windows 压缩包：`Windows-Dynamic-Island-1.0.3.zip`
