# 灵动岛 1.0.4

这个版本修复 Sparkle 更新版本号倒退，并增加菜单栏图标收纳开关。

## Mac

- 修复从旧版本更新时 Sparkle 因内部 build 号倒退而判断“没有更新”的问题
- 新增「菜单栏图标收纳」开关，默认开启
- 关闭收纳后卸载收纳分隔符，已收纳图标恢复到菜单栏
- 关闭收纳后停止收纳枚举、整理模式和单图标收纳操作
- 重新开启后恢复收纳功能和已保存的收纳偏好

## Windows

- Windows 版本同步更新到 1.0.4

## 说明

- Mac 安装包：`Mac-Dynamic-Island-1.0.4.pkg` / `Mac-Dynamic-Island-1.0.4-intel.pkg`
- Windows 压缩包：`Windows-Dynamic-Island-1.0.4.zip`
