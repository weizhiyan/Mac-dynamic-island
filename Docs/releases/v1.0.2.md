# 灵动岛 1.0.2

这个版本把 Windows 版和 Mac 版放到同一个仓库、同一条 GitHub Release 里。已经安装 1.0.1 的 Mac 用户可以直接在应用里检查更新。

## Mac

- 菜单栏图标收纳：把系统菜单栏图标收进灵动岛弹窗，支持拖拽整理
- 外接屏 / 空间切换时自动校正岛屿位置
- 启动脚本改用稳定签名身份，避免每次重建都要重新授权辅助功能
- 设置页、悬停气泡和应用网格的交互修正

## Windows

- 首次公开发布：顶部黑色岛体、应用网格、磁吸放大、浅色名称气泡
- 设置窗口对齐 macOS 系统设置（侧栏 + 白色分组）
- 托盘和设置页可检查更新；启动时若有新版本会气泡提示
- 下载 `Windows-Dynamic-Island-1.0.2.zip`，解压后运行 `DynamicIsland.exe`

## 说明

- Mac 安装包：`Mac-Dynamic-Island-1.0.2.pkg` / `Mac-Dynamic-Island-1.0.2-intel.pkg`
- Windows 压缩包：`Windows-Dynamic-Island-1.0.2.zip`（自包含 exe，无需安装 .NET）
- 1.0.1 的 Mac 用户走 Sparkle 应用内更新；Windows 用户走 GitHub Release 检查更新
