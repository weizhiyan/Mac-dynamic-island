# Mac Dynamic Island 1.0.0

First public release.

## Highlights

- Fluid Dynamic Island style notch launcher for macOS
- Quick app launcher with customizable shortcuts
- Drag-to-reorder shortcut apps
- Adjustable trigger area and animation timing
- macOS-style settings panel
- Menu bar controls

## Install

Download `Mac-Dynamic-Island-1.0.0.dmg`, open it, then drag `DynamicIsland.app` into Applications.
