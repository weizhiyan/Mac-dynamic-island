# 灵动岛 1.0.0

第一个公开版本。

## 亮点

- 面向 Mac 刘海区域的黑色灵动岛快捷启动器
- 支持自定义快捷应用、拖拽排序和右键管理
- 支持图标大小、展示数量、间距、触发区域和动画速度调整
- 可在设置里开启开机自启动
- 启动后隐藏 Dock 图标，只保留菜单栏入口
- 安装脚本会覆盖旧版本并清理重复副本

## 安装

下载 `Mac-Dynamic-Island-1.0.0.dmg` 后打开，双击 `安装灵动岛.command` 即可自动安装到 `/Applications/灵动岛.app`。
