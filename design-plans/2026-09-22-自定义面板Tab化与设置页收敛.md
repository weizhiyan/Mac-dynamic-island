# 自定义面板 Tab 化、设置页收敛、弹窗延迟与播放自动拉起

Written against: 预览收起联动与菜单栏弹窗收敛已交付（`2026-09-22-预览收起联动与菜单栏弹窗收敛.md`）

## 目标

集中处理六点验收反馈，另修一个同链路顽疾：① 点状态栏图标后弹窗要延迟一下才弹出；② 自定义面板的实时预览要固定在顶部，不随参数区滚动；③ 尺寸微调（圆角/顶部偏移）后真实灵动岛要立即跟着变；④ 面板参数按类型分成 tab；⑤ 设置页布局与交互深度收敛；⑥ 没打开音乐软件时点顶部播放要能自动把软件拉起来播放。

## Evidence chain

- Surface: `AppDelegate.showMenuBarPopover`、`IslandCustomizeView`、`IslandWindowController.setupLayoutObservers`、`SettingsView`、`MediaPlayerStore.execute`。
- Problem:
  - ① `showMenuBarPopover` 里 `MenuBarIconManager.refreshNow()` 同线程跑完 AX 枚举（实测 36~285ms）才 `pop.show()`，枚举期间主线程被占，弹窗合成被推迟。
  - ② 预览区和参数区同一个 ScrollView，参数一多预览就被滚出屏幕。
  - ③ `expandedCornerRadius`/`compactCornerRadius`/`topBarYOffset` 不在 `rebuildLayout` 观察列表里，Stepper 改了数值但 gooey 图层 path 不重画。
  - ④ 布局/收起态/展开态/动画四类参数平铺在一个长页面里。
  - ⑤ 设置页「常用调整」「应用网格」与自定义面板重复；外观缺圆角组；参数区间不统一。
  - ⑥ 未绑定播放器时点播放无反应；绑定Spotify但未授权时 `checkPermission` 的 `AEDeterminePermissionToAutomateTarget` 在本机无限期阻塞（独立 CLI 进程实测 >30s 不返回，askUserIfNeeded=false 同样挂），串行 `backendQueue` 被卡死，`isBusy` 永真，后续播放/切歌全部静默失败，播放器也打不开。
- Design evidence: 用户验收截图（弹窗延迟、预览滚动、Stepper 无效果）；本机实测日志 `REFRESH enumerate=309ms enumOnMain=false`（后台枚举生效）与 `EXEC backend entered` 后无返回（预检挂死）。
- Owner: 弹窗时序归 `MenuBarIconManager`；面板结构归 `IslandCustomizeView`；几何观察归 `IslandWindowController`；设置页归 `SettingsView`；播放链路归 `MediaPlayerStore`。
- Scope: 不碰收纳/整理/拖拽合成逻辑，不动灵动岛渲染本身。
- Uncertainty: Apple Events 授权弹窗在本机对自签名 LSUIElement app 不展示（无可见 TCC 对话框），因此不再依赖预检，直接走脚本执行让系统原生流程处理。

## Design decision

### 0. 修复「点状态栏图标先跑一个操作」

- `restoreSavedPreferencesIfNeeded` 原来对 savedStashed 图标用 `visibility != .hidden` 触发恢复。被系统隐藏的图标（微信实测 frame `(1203,-1,40x24)`，y=-1 停泊菜单栏上方、屏幕不渲染）被判 `.notDisplayed`，于是每次刷新都展开分隔符（菜单栏整体位移）→ 等 0.6s → 空搬一次，用户 perceived 成「点图标先有个操作再弹窗」。
- 改为 `visibility == .visible` 才触发：只有正显示在菜单栏上的才需要搬收纳；系统隐藏/未上栏的搬不动也不必搬。真收纳态图标（分隔符左侧 x≈-3765）本就判 `.hidden`，不受影响。

### 1. 枚举挪后台，弹窗零等待

- `MenuBarIconManager` 增 `refreshQueue`（`.userInitiated` 串行）：`refresh()` 只负责入队，`refreshNow()` 的 AX 读取全部在后台完成，结果 `DispatchQueue.main.async` 发布。
- `isEnumerating` 防重入；`shouldThrottleRefresh`（1s 内跳过）防弹窗反复开合时重复扫进程；所有 `refreshNow()` 调用点改走 `refresh()`。

### 2. 预览区固定顶部

- `IslandCustomizeView` 重构：`previewSection` 移出 ScrollView 常驻顶部（含「展开态/收起态」切换与「屏幕上真实岛屿同步更新」说明）；参数区各自独立 ScrollView，互不滚动。

### 3. 几何参数接入重建观察

- `setupLayoutObservers` 的 `layoutChanges` 加入 `$expandedCornerRadius`、`$compactCornerRadius`、`$topBarYOffset`，Stepper 一改即触发 `rebuildLayout`，gooey path 与紧凑带立即重绘。

### 4. 参数 tab 化

- 新增 `CustomizeTab`（布局/收起态/展开态/动画）分段控件；`onChange(of: tab)` 自动切预览态（收起态→compact，展开态/动画→expanded）；删旧 `geometrySection`，参数按类型归入四个 tab。
- 动画 tab 配 `CustomizeCurvePicker`：贝塞尔预设（默认/线性/轻快/回弹）+ custom，避免手写控制点。

### 5. 设置页收敛

- 删「常用调整」「应用网格」两组（与自定义面板重复，面板入口已在「自定义布局」组）；外观页新增「圆角」组（收起/展开圆角）；统一参数区间；`StepperSetting` 行布局对齐（label 118 + Spacer + Stepper）；动画页加「试一下」直接播展开动画；音乐 caption 补自动绑定说明。

### 6. 播放自动拉起 + 移除会挂死的权限预检

- `MediaPlayerStore.execute(_:)` 开头 `ensureBinding()`：未绑定/绑定已卸载时自动绑第一个已安装播放器并持久化，随后 `openApplication` + `play` 路径本就支持拉起。
- **根因修复**：删掉 `checkPermission`（`AEDeterminePermissionToAutomateTarget` 预检）。它在本机对当前签名身份无限期阻塞，把串行 `backendQueue` 卡死、`isBusy` 永真，播放控制全废。改为直接发 AppleScript：系统走原生授权流程，脚本失败时已有的 `isPermissionError` 识别（消息含 not authorized/not permitted/权限）负责提示。
- `deniedPlayers` 改由脚本结果驱动：`finishCommand` 里成功移除、权限失败写入；execute 的快速消息分支保留。

## Reuse

- 沿用 `MenuBarIconManager` 的枚举/分类管线和调试日志通道；`SettingsGroup`/`StepperSetting`/滑块等既有设置组件；`IslandCustomizeView` 的预览态联动机制（`onPreviewModeChanged`）；`AppleScriptRunner` 的 busy 锁与超时语义。

## Changes

- `Sources/DynamicIsland/Managers/MenuBarIconManager.swift`：`refreshQueue`、`isEnumerating`、`shouldThrottleRefresh`、`refresh()`/`refreshNow()` 拆分；调用点全改 `refresh()`。
- `Sources/DynamicIsland/Editor/IslandCustomizeView.swift`：`previewSection` 固定顶部；`CustomizeTab` 四分段 + `onChange` 联动预览态；`TimingCurvePreset`/`CustomizeCurvePicker`；删 `geometrySection`。
- `Sources/DynamicIsland/Window/IslandWindowController.swift`：三个圆角/偏移观察者加入 `layoutChanges`。
- `Sources/DynamicIsland/Views/SettingsView.swift`：删两组重复项、新增圆角组、统一区间、「试一下」组、`StepperSetting` 布局对齐、音乐 caption。
- `Sources/DynamicIsland/Managers/MediaPlayerStore.swift`：`ensureBinding()`；删 `checkPermission`；`finishCommand` 维护 `deniedPlayers`。
- `Sources/DynamicIsland/AppEntry.swift`：`testIslandAnimation()`（设置页「试一下」）；保持 popover 三按钮与后台刷新调用。

## Validation

- `swift build --disable-sandbox` 通过；`zsh Scripts/test-notch-rendering.command` 全量通过（含弹窗三按钮、设置页入口、预览联动、菜单栏可见性判定）。
- 真机（临时 `DYNAMIC_ISLAND_AUTOTEST` 钩子，已删）：面板 2.5s 自动打开，截图确认预览固定顶部、四个 tab、切 tab 预览态联动、真实岛屿同步展开（顶部出现应用网格）。
- 弹窗延迟：日志 `REFRESH enumerate=309ms enumOnMain=false`（枚举在后台线程，主线程不被占）。
- 播放拉起：AUTOTEST 11s 触发 `togglePlayPause`，Spotify（未运行）被自动拉起；随后 `EXEC backend entered → running -> script` 无阻塞，`isBusy` 正常复位（23s 的 pause 命令能再次进入，修复前会被 guard1 拦死）。
- 修复前对照：`EXEC backend entered` 后 `checkPermission` 无返回，23s 第二次命令 `busy=true` 被拦，媒体控制全废。
- restore 修复验证：埋点实测点击后 `PUBLISH done → RESTORE trigger → MOVE begin 微信`（旧行为，每次开弹窗都搬）；修复后启动与开弹窗均无 `🧲 收纳` 新增，`已收纳(0)`，微信归 `未上栏`。

## Scope

- 只影响菜单栏弹窗时序、自定义面板结构、设置页内容与播放控制链路；不动灵动岛渲染与收纳拖拽逻辑。
