# 组件化自定义编辑面板

Written against: 当前工作区（灵动岛已具备收起态音乐带与展开态顶栏摘要）

## 目标

参照 Safari「自定义工具栏」的编辑模式，为灵动岛提供一套组件化自定义面板：顶部刘海左右两侧、展开态内容区三个槽位都可以从组件库拖入组件；面板上方按真实比例预览岛屿，几何参数可实时微调；所有改动实时同步到屏幕上方真实的灵动岛。组件以注册表形式管理，后期新增组件只改一处。

## Evidence chain

- Surface: 菜单栏 popover 新增「自定义」入口；新窗口 `IslandCustomizeView`；展开态 `IslandRootView`。
- Problem: 顶栏左音乐摘要/右性能摘要写死在 `IslandTopControls`，内容区只有应用网格；紧凑带与展开态几何只能去设置页逐个翻，改动后看不到实时效果。
- Design evidence: 用户提供的 Safari 自定义工具栏截图（上方实时预览、下方组件网格、右下角完成）。
- Owner: 组件注册表归 `Sources/DynamicIsland/Editor/IslandComponent.swift`；槽位持久化归 `Sources/DynamicIsland/Managers/SettingsStore.swift`；面板窗口归 `Sources/DynamicIsland/AppEntry.swift`；实时预览锁定归 `IslandWindowController`。
- Scope: 主屏刘海/收起带/展开内容区；不影响副屏与菜单栏收纳逻辑。
- Uncertainty: 真实岛屿嵌在屏幕顶端，面板必须与之错开且不被全屏应用挡住。

## Design language

- Audited surface: macOS 灵动岛及其菜单栏 popover、设置页。
- Design sources: 现有 `SettingsGroup`/`NumericSetting`/`SliderSetting` 卡片式设置组、popover actionBar。
- Documented decisions: 黑色主体不变；面板用系统窗口样式 + 分段控件 + 虚线投放区；组件 chip 用图标 + 文案 + 移除按钮。
- Governing owners: `IslandComponentRegistry` 是组件唯一来源；`SettingsStore.components(in:)` 是槽位唯一读写入口；真实岛屿渲染仍由 `IslandRootView` 单一承载。
- Explicit exceptions: 面板本体不复用灵动岛窗口，几何微调直接绑定既有设置项，不新增第二套参数。

## Design decision

### 1. 组件注册表

`IslandComponentDescriptor` 描述 id、标题、SF Symbol、内容区高度、可出现的槽位，以及 `makeContent(slot) -> AnyView`。新增组件 = 实现视图 + 在 `IslandComponentRegistry.all` 登记一条。初始组件：音乐摘要、性能摘要、时钟、电池、固定间距、可调间距、应用网格（仅内容区）。间距组件按槽位自适应横竖方向。未知 id 返回空视图，旧配置不崩。

### 2. 槽位模型与持久化

`IslandSlot`（topLeft/topRight/body）三段有序 id 列表存进 `SettingsStore`（`didSet` 写 UserDefaults）。首次启动默认：左 = 音乐摘要（绑定了播放器才放）、右 = 性能摘要、内容区 = 应用网格，与改前行为一致。`moveComponent` 统一处理新增、跨槽位移动、同槽位换序、去重；`bodyComponentsHeight` 把内容区组件高度计入 `expandedHeight`，新增组件时岛屿窗口自动变高。

### 3. 编辑面板

上方「实时预览」舞台：一块屏幕 mock（假菜单栏 + 壁纸），岛屿挂在顶部正中间按真实尺寸等比缩放；展开态直接复用 `IslandRootView`（所见即所得），收起态用与 `NotchDetector` 一致的刘海几何绘制黑色刘海带 + 头像 + 波纹示意。中段三个槽位（虚线投放区 + FlowLayout chip + × 移除 + 每个 chip 可作插入点）与组件库网格（`.draggable`/`.dropDestination`）。下段几何微调直接绑定既有设置：收起态带宽/高/顶部圆角/底部圆角/垂直偏移（含「自动匹配刘海」开关），展开态图标大小/列数/间距/左右边距/顶部间距/圆角。右下「完成」关闭面板，左下「恢复默认布局」只重置槽位。

### 4. 实时预览窗口行为

面板打开时 `IslandWindowController.beginLivePreview()` 强制展开真实岛屿并锁定：锁定期间任何收起请求（含移出悬停区）都被忽略，保证编辑时屏幕上方一直有真实预览；关闭面板 `endLivePreview()` 解除锁定并收起。面板窗口 `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]`，全屏应用里也能浮出来与真实岛屿同屏；窗口下移到刘海下方，两者不重叠。

## Reuse

- `IslandRootView`/`IslandTopControls`：面板展开态预览直接复用，不复制布局。
- `NotchDetector.compactBand` 的几何规则与 `CompactMediaView.contentWidth`：收起态预览与真实紧凑带一致。
- `SettingsStore` 既有几何参数：微调滑块只做绑定，不新增参数体系；布局变化经既有 0.3s debounce 观察者触发 `rebuildLayout()`。
- `MenuBarPopoverView.actionBar` 现有按钮模式：新增「自定义」入口。
- Exemplar: `AppEntry.showMenuBarPopover()` 的 popover 生命周期与 `openSettings()` 的手动建窗模式。

## Implementation phases

1. 注册表 + 新组件 + 槽位持久化（SettingsStore）。
2. `IslandRootView` 注册表化，默认配置回归验证。
3. 编辑面板（预览、槽位、组件库、几何微调）与窗口接入。
4. 真机拖拽/滑块/关闭流程验证 + `Scripts/test-notch-rendering.command` 回归。

## State machine

- 面板关闭：岛屿由悬停区控制（默认）。
- 面板打开：`isLivePreviewPinned = true` → 强制展开 → 布局变化经 `rebuildLayout()` 实时刷新 → 期间忽略收起请求。
- 面板关闭（完成/关闭按钮）：`isLivePreviewPinned = false` → 若仍展开则收起。
- 悬停触发期间打开面板：保持展开，不会出现「开着面板岛屿收起」的中间态。

## Validation

- `swift build --disable-sandbox` 通过；`zsh Scripts/test-notch-rendering.command` 全部通过。
- 真机：播放音乐 + 打开面板，确认（a）默认槽位渲染与改前一致；（b）多组件槽位截断/间距符合预期；（c）拖拽组件到槽位后真实岛屿与预览同步；（d）几何滑块实时影响收起带与展开态；（e）面板关闭后岛屿回到悬停控制。
- 无刘海屏：`NotchDetector` 回退几何下预览不崩溃。

## Scope

只做组件化自定义与几何微调，不新增组件数据源（天气/日历等后续按注册表扩展），不改菜单栏收纳逻辑，不改动画参数体系。

## Stop conditions

- 不再复制 `IslandRootView` 布局到面板；一律复用同一视图。
- 不为组件引入第二套持久化格式；槽位只用 id 数组。
- 不把几何参数复制进面板私有状态；滑块一律绑定 `SettingsStore`。
